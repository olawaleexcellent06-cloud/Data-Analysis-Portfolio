# SQL Data Analysis Projects

This folder contains SQL projects focused on data exploration, business analysis, and performance evaluation across different datasets.

## Project Focus

These projects demonstrate my ability to use SQL to analyze structured data, identify trends, and generate actionable business insights.

## Key SQL Skills Applied

* Data querying and extraction
* Data filtering and sorting
* Aggregate functions (SUM, AVG, COUNT, MIN, MAX)
* GROUP BY and HAVING
* JOIN operations
* Subqueries
* Revenue and performance analysis
* Business-driven data exploration

## Projects Included

### Northwind Sales Analysis

Sales performance analysis using transactional business data to evaluate customer revenue and product performance.

### Superstore Retail Analysis

Retail sales and profitability analysis across product categories and regions.

### Housing Price Analysis

Data exploration and pricing trend analysis using real estate datasets.

### E-Commerce Sales Performance Analysis

Comprehensive analysis of e-commerce transaction data using advanced SQL techniques to evaluate revenue trends, category performance, product size analysis, and joined product-sales insights.

## Purpose

The goal of these projects is to demonstrate practical SQL problem-solving skills and the ability to transform raw datasets into meaningful business insights.
